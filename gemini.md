# AI Assistant Operational Rules

## 1. Repository Boundaries
- **Trading Bot (Cloud) Repo:** Only ever push the compiled data payloads (e.g., `ml-insights.json` and `history.jsonl`) to this repository. Absolutely no source code, pipeline scripts, or internal logs should be sent to the cloud consumer.
- **ML Pipeline (Local) Repo:** All Python scripts, config changes, hyperparameter tuning adjustments, and research experiments must be committed and pushed strictly to this repository (`cucuradu/ml-pipeline`).

## 2. The Schema is Law
You must strictly adhere to the `ml-insights.json` API contract. Any outputs generated by the models must match the expected schema perfectly. Never rename keys or change data types without explicit permission.

## 3. Stability & Idempotency
- Do not refactor working code unless explicitly requested.
- Ensure scripts can be run multiple times a day without corrupting or duplicating history logs.
